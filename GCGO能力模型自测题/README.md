# GCGO 能力模型自测题

一套面向品牌营销体系不同岗位与层级的 32 题能力自测，配套两段式 AI 评估流程，输出个性化的 400 字综合评价。

---

## 能力模型

**5 个维度 × 16 个细项**

| 维度 | 细项 |
|---|---|
| 战略思维 | 战略理解力 / 市场洞察力 / 目标统筹力 / 闭环管理力 |
| 营销技能 | 流量管理 / 内容营销 / 私域运营 / 品牌公关 |
| 资产管理 | 客户管理 / 品牌管理 |
| 组织管理 | 向上管理 / 内部协作 / 跨部门协作 / 跨文化沟通 |
| 数智运营 | AI 协作 / 数据管理 |

每个细项对应 2 道题，共 32 题，每题 1–5 分。

---

## 文件说明

| 文件 | 面向对象 | 作用 |
|---|---|---|
| `品牌营销能力自测题-学员版.md` | 学员 | 答题用。无岗位、层级、维度提示，避免策略性作答 |
| `品牌营销能力自测题-评分密钥.md` | 评分 AI | 把学员答案按映射表算成 16 项细项分 + 5 维度分 + 总分，输出标准 JSON |
| `品牌营销能力自测题-分数解读指南.md` | 解读 AI | 基于评分 JSON，按 10 种能力模式 + 4 段结构，生成约 400 字的综合评价 |
| `README.md` | 评估方 | 本文件，说明整套测评的使用流程 |

## 使用流程

```
学员答题表
    │
    ▼
[评分 AI]  ← 吃《评分密钥》
    │
    ▼
JSON（细项分 / 维度分 / 总分）
    │
    ▼
[解读 AI]  ← 吃《分数解读指南》
    │
    ▼
约 400 字综合评价
```

### 第 1 步：分发学员版给学员

让学员答完 32 题，按以下格式提交答题表：

```
Q1: B    Q2: A    Q3: E    Q4: C
Q5: B    Q6: E    Q7: D    Q8: B
Q9: E    Q10: C   Q11: D   Q12: E
Q13: B   Q14: E   Q15: B   Q16: D
Q17: B   Q18: C   Q19: A   Q20: E
Q21: B   Q22: D   Q23: D   Q24: D
Q25: E   Q26: D   Q27: E   Q28: E
Q29: D   Q30: E   Q31: C   Q32: D
```

### 第 2 步：调用评分 AI

把《评分密钥》作为 system prompt 的一部分，把学员答题表作为 user input，让 AI 输出标准 JSON。建议参数：

- temperature: **0**（评分是确定性任务，不需要创造性）
- 输出格式：JSON（不包裹 Markdown 代码块）

### 第 3 步：调用解读 AI

把《分数解读指南》作为 system prompt 的一部分，把上一步的 JSON 作为 user input，让 AI 输出 400 字评语。建议参数：

- temperature: **0.4–0.6**（需要语言生成的灵活性，但仍要保持准确）
- 输出格式：纯文本（4 段，无标题，无标号）

### 第 4 步（可选）：人工 review

AI 生成的评语建议由 HR 或学员的直属上级做一次轻量 review，确保：

- 没有把分数读错
- 语气符合公司文化
- 发展建议在公司当前阶段可落地

## 设计原则

1. **学员看不出对错** —— 各选项措辞中性，5 分答案在 A–E 中随机分布，避免策略性作答
2. **场景覆盖多岗位多层级** —— 从素材投放到品牌架构，从向上管理到跨文化协作，IC 到总监均能在题目中找到对应场景
3. **分数模式驱动解读** —— 不用"X 分对应一段固定话术"，而是基于 10 种能力模式（战略型 / 执行型 / 落差型 / 战略-执行错位 等）做结构化诊断，让评语千人千面
4. **两段式 AI pipeline** —— 评分（确定性，低 temperature）与解读（创造性，中 temperature）分离，便于独立验证和调试

---

## 使用建议

- **自评 + 他评对照**：建议同一员工由"本人 / 直属上级 / 1–2 名跨部门协作方"分别作答，差异本身就是 1on1 对话的起点
- **半年复测**：每 6 个月复测一次，跟踪雷达图变化，作为晋升、调岗、培养计划的输入
- **不做排名**：建议作为成长工具使用，而非全员排名工具
- **岗位权重可定制**：不同岗位可对 16 个细项分配不同权重（如品牌总监侧重战略思维 + 资产管理，私域负责人侧重私域运营 + 客户管理 + 内容营销）
