## 三、计算规则

### 步骤 1：题目得分
对每一题，根据学员的选择字母，按上表查得 1–5 分。

### 步骤 2：细项得分（保留 1 位小数）
```
细项得分 = (该细项第1题得分 + 该细项第2题得分) / 2
```
共 16 个细项得分，取值范围 1.0 – 5.0。

### 步骤 3：维度得分（保留 1 位小数）
```
维度得分 = 该维度下所有细项得分的算术平均
```
- D1 战略思维 = (S1 + S2 + S3 + S4) / 4
- D2 营销技能 = (S5 + S6 + S7 + S8) / 4
- D3 资产管理 = (S9 + S10) / 2
- D4 组织管理 = (S11 + S12 + S13 + S14) / 4
- D5 数智运营 = (S15 + S16) / 2

### 步骤 4：总分（保留 1 位小数）
```
总分 = 16 个细项得分的算术平均
```
> 注意：总分**按细项平均**，不是按维度平均；这样可以避免维度内细项数不同造成的权重失衡。

## 四、边界与异常处理

| 情况 | 处理方式 |
|---|---|
| 学员某题未作答 | 该题计为 3 分（中性默认值），并在输出中标记 `missing: true` |
| 学员某题选了非 A–E 的字母 | 同上，记为 3 分并标记 `invalid: true` |
| 学员同一题选多个 | 取所选字母对应分值的平均，向下取整为整数（1–5） |
| 学员答题表格式异常无法解析 | 输出错误提示，不强行评分 |
